# Command reference

Generated by `npm run docs:commands` from the live command registry.

On the **userbot** commands start with the prefix (default `.`); on the **control bot** they start with `/`.
Options look like `--chat=@name`, flags like `--yes`. Destructive commands always show a dry-run first (see SECURITY.md).

## Permission scopes (self mode)

- `self` — personal helpers (reminders, transforms, translate, AI on text you provide)
- `automation` — auto-reply rules and scheduled tasks
- `search` — search and export chat history
- `media` — inspect and download media
- `messaging` — send/edit/delete/forward as the account
- `chatadmin` — group/channel moderation (needs real admin rights too)
- `master` — only the master admin from `.env`

## Access (master)

| Command | Scope | What it does |
| --- | --- | --- |
| `audit [n]` | master | Recent audit-log entries (administrative and destructive actions) |
| `backup` | master | Back up local configuration (settings, grants, rules, tasks, plugin state) |
| `config` | master | Show non-secret settings |
| `grant <user id> [scopes] [--note=text]` | master | Enable "self mode" for a user. Scopes: self, automation, search, media, messaging, chatadmin (default: self) |
| `revoke <user id>` | master | Remove a user's self mode |
| `suspend <user id> \| resume <user id>` | master | Temporarily disable / re-enable a user without deleting their grant |
| `users` | master | List users who have self mode |

## Automation

| Command | Scope | What it does |
| --- | --- | --- |
| `remind <when> <text> [--repeat=1h]` | self | Personal reminder (10m, 2h30m, 18:30, tomorrow 09:00, 2026-12-31 23:59) |
| `reminders [--all]` | self | List your pending reminders/tasks (master: --all for everyone's) |
| `rule add\|list\|show\|on\|off\|del\|chat\|block …` | automation | Auto-reply / keyword rules. Run `rule` for details |
| `taskhistory [n]` | master | Recent scheduled-task runs |
| `unremind <id>` | self | Cancel a reminder/task you created |

## Contacts & profile

| Command | Scope | What it does |
| --- | --- | --- |
| `contacts [query] [--limit=20]` | search | List/search this account's contacts (id, name, username only) |

| `whois <user\|chat>   (or reply)` | search | Public info about a user or chat (phone numbers are never shown) |

## Group admin

| Command | Scope | What it does |
| --- | --- | --- |
| `adminlog [n] [--chat=...]` | chatadmin | Read the channel/supergroup admin log |
| `ban <user>\|(reply) [--chat=...]` | chatadmin | Ban a user (supergroups/channels; basic groups can only remove) |
| `kick <user>\|(reply) [--chat=...]` | chatadmin | Remove a user from the chat (needs the ban-users right; dry-run first) |
| `members [n] [--admins] [--search=text] [--chat=...]` | chatadmin | List participants (admins first with --admins) |
| `perms [--chat=...]` | chatadmin | Show what THIS account is actually allowed to do in the chat |

| `unban <user> [--chat=...]` | chatadmin | Lift a ban |

## Media

| Command | Scope | What it does |
| --- | --- | --- |
| `botfileid <file_id>` | media | Decode a Bot API file_id into MTProto identifiers |
| `dl   (reply to media) \| dl --chat=.. --id=..` | media | Download the media to the organised local folder (resumable, de-duplicated) |

## Messaging

| Command | Scope | What it does |
| --- | --- | --- |
| `del [n] [--chat=...]` | messaging | Delete this account's last n messages in a chat (dry-run first) |
| `draft <chat> <text>` | messaging | Save a draft in a chat (use `draft <chat>` with no text to clear it) |
| `drafts` | messaging | List all drafts |
| `edit <new text>   (reply to your own message)` | messaging | Edit one of this account's messages |
| `fwd <to chat>   (reply to a message)` | messaging | Forward the replied-to message |
| `history [n] [--chat=...]` | search | Show the last n messages of a chat (not stored) |
| `saved <text>` | messaging | Write a note to Saved Messages |
| `schedule <when> <chat> <text>` | messaging | Schedule a message with Telegram's own scheduler (works even if this app is offline) |
| `scheduled [--chat=...]` | messaging | List scheduled messages in a chat |
| `send <chat> <text>` | messaging | Send a text message as this account (paced; never bulk) |
| `unschedule <id...> [--chat=...]` | messaging | Cancel scheduled messages |
